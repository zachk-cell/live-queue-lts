1 What it is

The LTs Workshop Queue is the running order-of-service board for your TikTok Shop lives. It pulls paid orders straight from the TikTok Shop Order API while you're live, groups and prioritizes them by your rules, and shows a self-updating feed on three surfaces at once.

Three surfaces

  • Admin panel — where you pack from. Full detail, all controls.
  • Public page — what buyers watch. Position, username and a PRIORITY tag only; no totals or personal info.
  • Discord — an auto-updating mirror of the queue plus the LTs Box tally, with a few mod commands.

The core ideas

  • No typing. Orders ingest automatically from TikTok while you're live.
  • One slot per buyer. A buyer who orders again before you fulfill them merges into their existing slot instead of getting re-queued.
  • Item-driven priority. An order containing a priority item is staggered up the queue — woven in every other slot ahead of regulars, without overtaking whoever's at the top. An item counts as priority if it matches a keyword in ⭐ Priority items or is ticked ⭐ Priority in the back office inventory (no keywords needed).
  • Always listening. While you're live, orders build the queue. While you're offline, orders are still captured — break spots go to their break, everything else to Offline orders.
  • Nothing is ever lost. Every order is kept permanently in the sales history that powers reports, exports and metrics.
TimezoneEverything time-stamped in this queue is in Eastern time (EST/EDT). Where you type a time (Stream Clips), you type your own local clock and the app records and displays it in Eastern for you.

2 Getting in

  1. The operator guide & sandbox (this page and /sandbox) sit behind a shared guide password. Anyone helping out can be given that without handing over the admin login.
  2. The admin panel lives at a secret, unlinked URL and is protected by its own password. If two-factor is switched on, you'll also enter a 6-digit code from your authenticator (or a one-time backup code).
  3. Once you're in the panel, your login lasts about 30 days on that device, so you normally sign in once and stay in.
TipPractice everything in this guide risk-free on the interactive sandbox — it's a full copy of the board with make-believe orders. Nothing there is real; refresh to start over.

3 Going live

The board does nothing until you start a session. When you're ready to sell, hit ● Go Live at the top left of the panel and confirm.

What Go Live does, in order

  • Archives anything left over from a previous stream that wasn't properly ended (so nothing is lost), then clears the board for a fresh session.
  • Starts accepting orders. From this moment TikTok orders flow in automatically (polled every few seconds).
  • Auto-starts the Stream Clips timer at that exact moment and begins a fresh clip log for this stream. You can still fine-tune the start time by hand later.
  • Runs a pre-live backfill. It quietly pulls in any orders placed in roughly the 15 minutes before you went live, so a late start doesn't miss early buyers. This runs in the background — going live stays instant, and the orders stream in as they're fetched.
Why the backfill mattersPeople start buying the second you go on. If you were a few minutes late hitting Go Live, those orders still land in the queue. The backfill is idempotent — it only adds orders that aren't already there and are still unshipped, so it can never create duplicates.
Offline ordersWhile you're offline, orders are still captured (checked every 5 minutes): break spots go into their break and everything else lands in 🌙 Offline orders. When you hit Go Live, any offline order from the last ~15 minutes that hasn't been handled moves into the live queue — same as the pre-live backfill always did. Older offline orders stay in their own list.

5 Flags & badges — and what to do

Badges sit on the buyer's name row. Here's every one and the action it's asking for:

BadgeMeansDo this
PRIORITY The slot contains a configured priority item, so it is staggered up the queue. Priority orders are woven in every other slot rather than stacked — they move up faster than regulars but never bump whoever's already at the top.
N orders This buyer has N separate orders merged into one slot (items and total combined). Pack them together as one bag. Expand the row to see each order broken out.
＋ ADDED MORE ×N This buyer ordered again while already at #1 — their bag is probably being packed right now. The ×N is how many times they've added since reaching the top. Add the new item(s) to the bag in progress. Don't seal it assuming the slot was done. Only flashes while they are currently #1.
🔁 N earlier today This buyer already had order(s) fulfilled earlier this same stream. Decide whether this should be combined into one shipment with what you already packed.
⚠ SAME NAME id …a2f1 A different buyer in the queue has the exact same display name. These are different people (the queue tells them apart by buyer id, not name). Use the id …last4 tag and the order numbers to keep the two straight. Don't merge them.
⚠ CANCEL REQ A genuine cancellation was requested — the whole order, or a specific item. Expand the row to see exactly which item is flagged (it's highlighted). Do not ship or seal until the cancelled item is pulled.
⏸ ON HOLD — verify TikTok put the order On Hold for some other reason — address check, order combine/split, a sample/exchange, or a pending review. This is not a cancellation. Just verify before shipping. (Suppressed automatically if a real CANCEL REQ is already flagged.)

6 The fulfill loop

Working the board is a simple rhythm — always start from the top:

  1. Look at row 1. Read its badges (priority, added-more, cancel, same-name).
  2. Expand it if you need the full item list (see expanded view), print a 🏷 Label if you use them.
  3. Pack the bag. If it's a multi-order slot, everything in that slot goes together.
  4. Hit ✓ Fulfilled. That closes the whole buyer batch and moves it to Fulfilled this stream.
  5. The next slot slides up to #1. Repeat.
Slot merging, in practiceIf a buyer you already fulfilled orders again later, a fresh slot opens for them. If they order again before you fulfill them, it merges into the same slot — that's the N orders badge, and, if they were already at the top, the ＋ ADDED MORE flash.

7 Action buttons

On each slot

  • ✓ Fulfilled — closes the whole buyer batch and files it under Fulfilled.
  • ▲ Bump — force this slot to the very top. Only one slot can be bumped at a time; bumping a new one releases the last.
  • ✕ Remove — take the slot off the board without fulfilling it (e.g. the buyer cancelled). It moves to Cancelled this stream.
  • ▸ Expand — show/hide every item in the slot.
  • 🏷 Label — print a 2.25×1.25 shipping label with the username and order numbers.

Up top / in sections

  • ● Go Live / ■ End Live — start or stop the session.
  • ⭐ Priority items — edit the list of phrases that trigger priority (one per line, matched inside the item name).
  • Reset — clear the active board. Use with care.
  • ↩ Undo / Restore — on any Fulfilled or Cancelled row, put the slot back on the board (only if that buyer has no newer open slot).
  • ⬇ Export CSV — download the stream's orders (see wrapping up).

9 The LTs Box 📦

The LTs Box is LTs Workshop's per-variant sales counter. Each tracked variant gets a running unit total that persists across streams — it keeps climbing live after live until you reset it (for example when the bank is "hit").

How it counts

  • Units are tallied automatically when a slot containing a tracked variant reaches the top of the queue.
  • Matching is on the item text — a variant needs its variant phrase (and its product phrase, if one is set) to appear in the item name.
  • The counts are cumulative running totals, so they're not cleared by Go Live or End Live.

Adjusting a counter

  • You can manually set or reset any counter from the admin panel.
  • Every manual change is written to an audit log with the previous value, so a mistaken edit or reset is always recoverable.
Where it showsThe LTs Box tally appears on the admin panel, on the public page (label + count only), and as its own pinned LTs Box Tracker message in Discord.

10 Stream Clips

Stream Clips is a timestamp tool for your video editor. During the stream you flag moments worth clipping with one tap, and the app hands the editor a clean, copyable list.

The timer

  • The clip timer auto-starts the moment you hit Go Live, and a fresh clip log begins for that stream.
  • When you hit End Live the running timer freezes — but the start time and every clip are kept, so the list stays copyable for the editor afterward.
  • You only need 🕐 Set start time if you want to correct the auto-set start.

Times are typed local, recorded Eastern

ImportantYou type the start time and each clip time in your own local clock — whatever time you're looking at. The app records and displays it in Eastern (ET) for the editor. Elapsed times are the same in any timezone, so they always line up with the recording.

Marking & editing clips

  • Hit ✂ Time Clip to drop a clip at the current moment (the button unlocks once a start time is set).
  • Each clip row is fully editable: its clock time (type in your local time), its elapsed value (h:mm:ss since stream start), and a free-text note. Editing one keeps the other in sync.
  • Use ⧉ Copy list to grab the whole list for the editor, or Clear all to wipe it.

11 Paging & search

Page size

On a big live the active queue can get long. The Show N per page dropdown (10 / 25 / 50 / 100) controls how many slots render at once, with pager controls below. Your choice is remembered on that device.

Order-# search

The search box filters by buyer name or order number — full number or just the last few digits. Handy when a buyer reads out their order number in chat and you need to find their slot fast.

12 Discord & mod commands

When Discord is enabled, the bot keeps a single auto-updating live queue message in the channel (position, username and a ⭐/🔺 marker only — no totals or personal info, matching the public page), plus a separate pinned LTs Box Tracker message.

Mod commands

  • /queue — refresh / re-show the live queue message.
  • /fulfill [buyer] — mark the top slot (or a named buyer) fulfilled without opening the web app.
  • /bump <buyer> — bump a named buyer to the top.
NoteThe web dashboard is always the primary control surface — Discord mirrors it so mods and buyers can follow along and mods can help from their phone.

13 Breaks & labels 🎟

Items toggled 🎯 Break in 🔒 Back office → Inventory & pricing open a break automatically and stay out of the running queue, so a 40-spot break never clogs the board. Only toggled items do this — a listing with “break” in its name (like a *Box Break* pack) stays a normal queue item. The spot total is read from the listing name, e.g. “(33 Spot)”, and can be changed on the break. Toggle a new break listing on before it sells; ⚙ Break settings lists every toggled item. Regular items in the same order still queue as normal, and both sides are flagged so nothing gets missed.

Rounds & spots

  • Breaks are ripped in the order received — no combining. Each entry shows its spot number.
  • If the name includes a spot count (e.g. (33 Spot)) the break runs in back-to-back rounds of exactly that many spots. An order that runs past the end of a round is split — the overflow becomes the first spots of the next round (shown as part 1/2 · rest in R2).
  • Use ✎ Edit to set or change the total spots, ✓ Round N done to clear a whole round, or tick spots and ✓ Fulfil selected. Every fulfilled spot can be undone from the Fulfilled list.
  • Open breaks with spots left carry over when you End Live — numbering continues next stream.

Labels — one per seat, plus one shipping label per order

Seat labels

Every seat gets its own label: buyer name, SEAT 1 OF 3, SEAT 2 OF 3…, the break, the round + spot number and the order number.

Shipping label

Each order number gets one extra SHIPPING LABEL: buyer name, order number and how many items are in the order (break seats + any other items).

The mathLabels = seats + orders. 33 seats bought by 33 people = 66 labels; one person buying all 33 seats in one order = 34. If an order's seats run across two rounds, its shipping label prints with the round that holds its last seat — never twice, never missed.

The buttons show the exact count before you print: 🏷 All labels (18), 🏷 Round labels (12), and 🏷 3 on each row (that order's seats + its shipping label).

14 Offline orders 🌙

Anything bought while you're not live lands in 🌙 Offline orders, just below Fulfilled this stream (break spots go to their break instead). Each order is one tidy line — buyer, item count, total — and clicking it expands the full item list. Check it once a day:

  1. Orders are grouped by day, newest first. Cancel / on-hold flags show just like the queue.
  2. Tick orders (or ☑ Select all waiting) and hit 🏷 Print labels — one label per order, flagged OFFLINE ORDER with the items listed.
  3. Pack and ship, then ✓ Mark handled. Handled orders hide away; Show handled brings them back (and lets you ↩ Undo) for 7 days.
Mixed ordersIf an offline order also bought break spots, the row shows 🎟 + N break spots — the spots are in the break, the rest is here.

15 #1 buyer chat 💬

The 💬 Chat box (bottom-right of the panel) reads the TikTok LIVE chat. The #1 buyer tab shows only messages from whoever is #1 in the queue, so in a busy chat you can instantly see what the person being ripped is saying. All chat shows everyone, with the #1 buyer's messages marked. The two tabs stay in the same spot for quick switching.

  • Search: type in 🔍 to search the whole stream's chat by words, display name or @handle (it keeps thousands of messages, even across a restart). Matches are highlighted. Click anyone's name to see all of their messages. Esc or ✕ clears it.
  • ⚙ Chat settings: the LIVE account to read (the LTs streaming account, already set) and ↻ Reconnect. Chat connects automatically on Go Live and disconnects on End Live.
  • It's read-only — it never posts anything.
  • TikTok's official shop API has no chat access, so this uses an unofficial reader. If TikTok changes something it may show disconnected — hit ⚙ → ↻ Reconnect. Nothing else in the queue depends on it.

16 End Live & after-action reports 📋

When the stream is over, hit ■ End Live and confirm. This:

  • Archives the entire stream (fulfilled, cancelled and anything still unfulfilled) and clears the board. Open breaks with spots left carry over.
  • Freezes the Stream Clips timer (start time and clips are kept).
  • Builds the stream's after-action report and offers to open it straight away.
  • Saves the stream's chat with its report (💬 Chat log) and starts the next stream with an empty chat box.

The after-action report

  • Headline numbers: sales before coupons (item list prices — a $84.99 spot bought with a TikTok coupon counts as $84.99, with “paid $0.01 · coupon $84.98” noted under it), estimated net revenue, orders, unique buyers, units, average order.
  • A revenue breakdown: seller discounts, TikTok fee, streamer commission, shipping (estimate), cost of goods and consignee payouts → net. TikTok-funded coupons are paid back by TikTok, so they don't reduce revenue.
  • TikTok actuals: as TikTok settles orders (about a week after delivery) the report shows the real settlement, fees, shipping label cost and refunds next to the estimates, plus refund-request, refund, dispute and cancellation rates. Each order shows “settled $…” once paid out, and a REFUND REQ / REFUNDED tag if the buyer asked for money back.
  • Own stock vs consignment shown separately (gross, paid to consignees, net to us), with a per-consignee table.
  • Every unique buyer with their order numbers, items and total spend; items sold; sales by hour; breaks; cancellations.

Because they contain the full financials, after-action reports live in the 🔒 Back office (its 📋 Reports tab lists every past stream, kept permanently) and need the back-office password. Between streams the 📋 Prior stream reports box on the panel links straight to the latest one; it hides as soon as you Go Live. The money-free 📦 Shipping reports in the panel header need no extra password, so the shipping team can use them. Each report exports to ⬇ Excel (formatted workbook) or ⬇ PDF (print → Save as PDF).

📦 Shipping report (top of any report) is the version for the shipping team: buyers A–Z with every order number, item and quantity, a tick box per order, items to pull from partly-cancelled orders, refund flags and the do-not-ship list — no money shown. Print it or save it as a PDF. 💬 Chat log shows that stream's saved chat, searchable.

Don't forgetAlways End Live when you're done — that's what closes the stream's report. If you leave a session open, the next Go Live archives the leftovers for you.

17 Back office 🔒

The 🔒 Back office holds the money side and has its own password, separate from the queue login (created on first use, or set in Render as BACKOFFICE_PASSWORD). It auto-locks after 12 hours.

📦 Inventory & pricing

Every item with its price, stock, your cost, consignment terms, units sold and net per unit. Price and stock change the live TikTok listing, so they're deliberate: ✎ → new value → Save → confirm. Click the Price or Stock header to sort high → low, again for low → high, again to clear. Deactivated and Deleted listings sit in their own collapsed sections at the bottom — click one to open it.

⭐ Priority tick

Tick ⭐ Priority next to any item in Inventory & pricing and every order containing it is treated as PRIORITY in the live queue — instantly, matched by the exact TikTok item, so no keyword matching. Keywords still work alongside (or leave them empty). Ticks are logged in the Changelog.

🎯 Break toggle

Toggle 🎯 Break on listings that are breaks (spots). When one sells, its spots open their own break section in the live queue instead of the queue. Untoggled items — Box Break packs included — are normal queue items. Toggles take effect for orders from that moment on and are logged in the Changelog.

Consignment

Mark any item (or every variant of a product) as consigned, name the consignee and their share — a % of the sale or a fixed $ per unit. Terms are stamped onto each sale as it happens, so changing them later never rewrites past payouts.

💵 Profit & exports

Profit for any range (today → all time, or custom), live + offline combined, live only, offline only, or live vs offline side by side — grouped by stream, day, week, month, quarter or year. Download it all as a formatted Excel workbook.

📈 Sales metrics

Best days and hours (with a day × hour heat map), sales by month, top spenders, best sellers, price points, time to sell, consignment profitability and time to sell, and live vs offline.

🧾 Changelog

Every cost, consignment, price, stock and setting change — what it was, what it became, when, and whether TikTok accepted it. Downloadable as CSV.

⚙ Settings

TikTok fee (6%), streamer commission (10%), shipping estimate (fixed $ per order, default $8, or % of order), report time zone, password, and a one-click import of past TikTok orders so metrics have history from day one.

EstimatesNet revenue = gross − TikTok fee − commission − shipping estimate − cost of goods − consignee payouts. Shipping is always labelled as an estimate, and any sales with no cost entered are flagged so net is never silently overstated.

18 Golden rules

1
Always pack from the top down. Row 1 is always the next bag. Trust the sort.
2
Go Live before you sell, End Live when you're done. Offline orders are still captured — check 🌙 Offline orders daily.
3
Red ⚠ CANCEL REQ = stop. Expand, pull the flagged item, and never seal until it's handled.
4
Green ＋ ADDED MORE = add to the bag in progress. The buyer bought again while at #1.
5
Same name ≠ same person. Use the id …last4 tag and order numbers to tell them apart.
6
Type clip times in your local clock. The app records them in Eastern for the editor.
7
The LTs Box persists. Don't reset a counter unless the bank is actually hit.
8
Break labels = seats + orders. Print with 🏷 All labels or by round — the count on the button is exactly what will print.
9
Price and stock edits are live. In the back office they change the real TikTok listing — every edit asks you to confirm and is logged.

19 Quick fixes

Orders aren't coming in. Check the LIVE badge — if it says OFFLINE, hit Go Live. If it's live, check the green Live feed dot; a dropped feed reconnects on its own, and refreshing the page pulls the latest state.
I started the queue late and missed early orders. The pre-live backfill already grabs the last ~15 minutes automatically on Go Live. It's idempotent, so it never duplicates what's there.
I fulfilled the wrong slot. Open Fulfilled this stream and hit ↩ Undo on that row — it returns to the board (as long as the buyer has no newer open slot).
A buyer added more after I started their bag. Look for the ＋ ADDED MORE flash on #1 and expand the row — the new items sit under Added since top of queue.
Two buyers have the same name. That's the ⚠ SAME NAME flag. Match on the id …last4 tag and the order number, not the name.
The Time Clip button is greyed out. Set a stream start time first (it's normally auto-set at Go Live) — the button unlocks once a start exists.
An order came in while we were offline — where is it? In 🌙 Offline orders (or in its break, if it bought break spots). If it was placed in the last ~15 minutes before Go Live, it moved into the live queue.
The chat box says disconnected. Make sure the @username is set and you're actually live on TikTok, then hit ↻ Reconnect. The queue itself is unaffected.
Back office says "waiting for product access". The streamer needs to add the TikTok Product permission to the app. Costs, consignment, reports and metrics all work meanwhile.
Net revenue looks too high. Check for the "no cost entered" warning — add costs in Inventory & pricing and every report updates instantly.
A LTs Box number looks wrong. You can set or reset it manually in the panel; every change is logged with the old value, so nothing is lost.
Still stuck?Nothing you click can lose data — the board is saved continuously and every ingest is idempotent, so refreshing is always safe. Practice the whole flow on the sandbox whenever you like.
